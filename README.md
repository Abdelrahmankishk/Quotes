# Random Quote Generator — JavaScript

A **JavaScript-based Random Quote Generator** that displays randomly selected quotes and their authors from a predefined collection. This project focuses on practicing JavaScript fundamentals, including arrays of objects, random number generation, DOM manipulation, and event handling, through a simple interactive web application.

## 📌 Project Overview

The Random Quote Generator is a small interactive application built to practice core JavaScript concepts and understand how JavaScript interacts with HTML elements through the DOM.

The application stores a collection of quotes and their authors in an array of objects. Whenever the user clicks the **New Quote** button, JavaScript generates a random index, retrieves the corresponding quote and author, and dynamically updates the page content.

HTML and CSS are used to build and style the interface, while JavaScript handles the application's main functionality and logic.

## ✨ Key Features

- **Random Quote Generation:** Selects and displays a random quote from a predefined collection.
- **Quote Collection:** Stores multiple quotes and their authors using an array of objects.
- **Author Attribution:** Displays the author associated with each selected quote.
- **Dynamic DOM Updates:** Updates the quote and author directly without reloading the page.
- **Interactive Event Handling:** Generates a new quote whenever the user clicks the New Quote button.
- **Random Selection Logic:** Uses random number generation to select different entries from the collection.
- **Modern User Interface:** Dark theme with glassmorphism, gradient effects, and CSS animations.
- **Responsive Design:** Adapts the interface to different screen sizes.
